- [ ] T001 FR-S4-001 (S4-AC1): The system SHALL define an OTP error type representing an invalid passcode, identified by the error_code value 'INVALID_PASSCODE'. When this INVALID_PASSCODE error type is thrown and propagated to the HTTP layer, the centralized error handling mechanism SHALL produce an HTTP response with status code 422 and an error body whose error_code field equals 'INVALID_PASSCODE'.
- [ ] T002 FR-S4-002 (S4-AC2): The system SHALL define an OTP error type representing a locked OTP, identified by the error_code value 'OTP_LOCKED'. When this OTP_LOCKED error type is thrown and propagated to the HTTP layer, the centralized error handling mechanism SHALL produce an HTTP response with status code 409 and an error body whose error_code field equals 'OTP_LOCKED'.
- [ ] T003 FR-S4-003 (S4-AC3): The system SHALL define an OTP error type representing an invalid account state, identified by the error_code value 'ACCOUNT_STATE_INVALID'. When this ACCOUNT_STATE_INVALID error type is thrown and propagated to the HTTP layer, the centralized error handling mechanism SHALL produce an HTTP response with status code 422 and an error body whose error_code field equals 'ACCOUNT_STATE_INVALID'.
- [ ] T004 FR-S4-004 (S4-AC4): The centralized error serialization logic for all OTP-specific errors (including at minimum INVALID_PASSCODE, OTP_LOCKED, and ACCOUNT_STATE_INVALID) SHALL always include both an outcome field and an error_code field in the HTTP response body; the precise value of the outcome field (for example, 'error') is not constrained by this requirement but MUST be present whenever an OTP error is serialized.
- [ ] T005 FR-S4-005 (S4-AC5): The error-handling middleware or equivalent centralized mechanism SHALL map each OTP error type to its corresponding HTTP status code and error_code value so that controllers and route handlers can surface OTP errors by throwing or propagating them without adding per-controller mapping logic (for example, no switch or if-else blocks in controllers to translate INVALID_PASSCODE, OTP_LOCKED, or ACCOUNT_STATE_INVALID into status codes or error_code strings).
