# Feature Specification: US-003

## User Scenarios & Testing
- **US-003**: Given I have successfully changed my multi-factor authentication settings, when the change is processed, then I should receive a notification confirming the change was made.
- **US-003**: Given a notification is sent, when I check my email or messages, then I should see the notification detailing the change.

## Functional Requirements
- FR-001: The system must send a notification to the user once their multi-factor authentication settings have been successfully changed.
- FR-002: The notification sent to the user must include details of the change made to their multi-factor authentication settings.
- FR-003: The user must be able to view the notification about the change in their email or messaging applications.
